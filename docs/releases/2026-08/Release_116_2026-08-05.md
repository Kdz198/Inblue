## 🎯 Tổng quan mục tiêu
Bản cập nhật này tập trung vào việc tăng cường khả năng giám sát và truy xuất dữ liệu trong hệ thống. Bằng cách bổ sung logging cho payload của các yêu cầu API, đội ngũ kỹ thuật có thể dễ dàng chẩn đoán lỗi và tối ưu hóa hiệu suất giao tiếp giữa các dịch vụ.

## ✨ Chi tiết thay đổi

### 🛠 Bảo trì hệ thống
- <kbd>cc28337</kbd> **Bổ sung logging cho API request payloads**: Triển khai cơ chế ghi nhật ký dữ liệu đầu vào tại `ApiClientImpl` nhằm hỗ trợ việc debug và theo dõi luồng dữ liệu của các yêu cầu API hiệu quả hơn.
