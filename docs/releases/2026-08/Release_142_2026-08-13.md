## 🎯 Tổng quan mục tiêu
Bản cập nhật này tập trung vào việc tối ưu hóa khả năng truy xuất dữ liệu trên trang quản trị, giúp đội ngũ vận hành có cái nhìn toàn diện và nhanh chóng hơn về thông tin khách hàng. Việc bổ sung chi tiết doanh nghiệp vào phản hồi API giúp quy trình kiểm duyệt và quản lý hồ sơ trở nên hiệu quả, đồng bộ hơn.

## ✨ Chi tiết thay đổi

### 🚀 Tính năng mới
- <kbd>f089f9f</kbd> **Bổ sung thông tin doanh nghiệp vào API AdminApplicationDetailResponse**: Cập nhật phản hồi API để hiển thị đầy đủ thông tin chi tiết của doanh nghiệp, giúp quản trị viên dễ dàng nắm bắt dữ liệu cần thiết trong quá trình xử lý đơn đăng ký.
