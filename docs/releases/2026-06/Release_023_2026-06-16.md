## 🎯 Tổng quan mục tiêu
Bản cập nhật này tập trung vào việc tối ưu hóa quy trình quản lý mẫu phỏng vấn nhằm đảm bảo tính toàn vẹn của dữ liệu. Đồng thời, chúng tôi đã khắc phục sự cố sai lệch mã phản hồi API để cải thiện độ ổn định và trải nghiệm tích hợp hệ thống.

## ✨ Chi tiết thay đổi

### 🐛 Sửa lỗi
- <kbd>5ab5ff3</kbd> **Cập nhật mẫu phỏng vấn**: Khắc phục lỗi trùng lặp dữ liệu khi cập nhật mẫu và điều chỉnh mã trạng thái phản hồi (status code) về đúng chuẩn để đảm bảo giao tiếp API chính xác.
